# Real-Life Patch Notes: The Comedy Changelog

One line, at most 160 characters: a changelog entry for a bug in real life or
human biology. `main.py` writes the entry to `$OUTPUT_DIR/entry.txt` (default
`/output`), UTF-8, no trailing newline, and prints the character count.

## Run

```sh
OUTPUT_DIR=/tmp/o python3 main.py
```
